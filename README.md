# Navalny VPN

Лёгкий VPN-клиент для Android с протоколами **Hysteria2** и **VLESS + REALITY**.
Главная цель — **минимальный расход батареи**. Интерфейс сделан на **Material 3 Expressive**
(официальная библиотека `androidx.compose.material3:1.5.0`).

## Возможности

- **Протоколы:** Hysteria2 (Salamander obfs, port hopping) и VLESS (REALITY / TLS / без шифрования,
  `xtls-rprx-vision`, транспорты tcp / grpc / ws / http / httpupgrade).
- **Импорт:** ссылки `hysteria2://`, `hy2://`, `vless://` из буфера обмена, вручную, по клику
  в браузере/мессенджере или **по QR-коду** (камерой или из картинки/скриншота), а также **подписки** (base64 или текст). Показываются остаток трафика
  и срок действия (`subscription-userinfo`).
- **Главная:** выбор сервера/подписки → большая кнопка подключения (морфинг форм MD3 Expressive) →
  время сессии, текущая скорость, общий трафик и график за последнюю минуту.
- **Исключения:** приложения, которые работают **мимо VPN** (поиск, системные приложения).
- **Настройки:** экономия батареи, сетевой стек, DNS, обход локальной сети, IPv6, MTU,
  автообновление подписок, оформление, постоянная VPN; в конце — «О приложении».
- **Оформление:** темы Авто / Светлая / Тёмная / **AMOLED** (чистый чёрный) и палитры
  Обои (Material You), Индиго, Закат, Лес, Фиолет, Океан, Роза — полные схемы MD3 строятся
  официальными алгоритмами Material Color Utilities из одного цвета.
- **Анимации MD3 Expressive:** кнопка подключения и карточка сервера непрерывно морфятся между
  `MaterialShapes` (и меняют форму при нажатии), активная «пилюля» навигации плавно перетекает
  между вкладками с эффектом растяжения. Можно отключить в настройках.
- Плитка в шторке быстрых настроек, поддержка «Постоянной VPN» (Always-on).

## Как экономится батарея

| Что сделано | Почему это важно |
|---|---|
| Ядро sing-box собрано **только с нужными модулями** (`with_quic`, `with_utls`, `with_gvisor`) | Меньше нативный код, меньше памяти и фоновых горутин |
| Go-рантайм загружается **только при подключении** | Открыть приложение ради настроек ничего не стоит |
| Стек **`system`** по умолчанию | TCP обрабатывает ядро Linux, а не userspace — меньше нагрузка на CPU |
| **Режим экономии**: keep-alive Hysteria2 раз в ~55 с вместо 10 с, TCP keep-alive VLESS 10 мин, UDP-сессии 1 мин, смена портов раз в 5 мин | Модем не просыпается каждые 10 секунд, когда туннель простаивает |
| Логи ядра **выключены**, нет sniffing и rule-set | Никакой работы на каждое соединение |
| DNS кэшируется в ядре, **только IPv4** по умолчанию | Вдвое меньше DNS-запросов |
| Адрес сервера резолвится **один раз** перед стартом | Нет bootstrap-DNS внутри туннеля |
| Локальная сеть и исключённые приложения **не попадают в TUN** | Их трафик вообще не проходит через приложение |
| gRPC command-server libbox **не запускается** | Нет лишнего сокета и потоков |
| Трафик/таймер считаются **только пока экран открыт** (`collectAsStateWithLifecycle`), из счётчиков ядра (`TrafficStats`) | При выключенном экране нет ни одного таймера |
| Уведомление **статическое**, таймер рисует система (`setUsesChronometer`) | Не нужно обновлять уведомление каждую секунду |
| В Doze ядро ставится на паузу (`CommandServer.pause()`) | Закрываются простаивающие соединения, таймеры ядра стоят |
| Плитка шторки — `ACTIVE_TILE` | Система не опрашивает её |
| Колбэк сети без `onCapabilitiesChanged` | На Android 13+ приложение не будят при каждом изменении уровня сигнала |
| QR-сканер (ZXing, без Google Play Services) держит камеру открытой только на экране сканирования | Никакой работы камеры в фоне |
| Анимации морфинга рисуются в фазе отрисовки (без рекомпозиций) и встают на паузу, когда приложение не на экране; их можно выключить | При выключенном экране — ноль кадров |
| Автообновление подписок — только при запуске, если прошло > 12 ч | Нет WorkManager и фоновых задач |

## Сборка

Ядро (sing-box `libbox.aar`) собирается отдельно и в репозиторий не коммитится.

### Через GitHub Actions (проще всего)

Workflow `.github/workflows/build.yml` сам собирает ядро, прогоняет тесты и собирает APK.
Готовые APK лежат в артефакте **navalny-vpn-apk** (отдельные под `arm64-v8a`, `armeabi-v7a`,
`x86_64` и универсальный).

Для подписи релизным ключом добавьте секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`,
`KEY_PASSWORD`. Без них APK подписывается debug-ключом.

### Локально

Нужны JDK 17+, Go 1.25+, Android SDK (platform 37) и NDK `28.0.13004108`.

```bash
export ANDROID_HOME=~/Android/Sdk
scripts/build-libbox.sh            # → app/libs/libbox.aar (≈5–10 минут)
./gradlew :app:assembleRelease     # → app/build/outputs/apk/release/
```

Чтобы собрать ядро только под свой телефон (быстрее): `scripts/build-libbox.sh android/arm64`.

## Структура

```
app/src/main/java/org/navalny/vpn/
├── App.kt                      — Application, ленивый запуск ядра
├── core/
│   ├── LinkParser.kt           — разбор hysteria2:// hy2:// vless:// и подписок
│   ├── ConfigBuilder.kt        — генерация конфига sing-box (все энергосберегающие параметры тут)
│   ├── SubscriptionFetcher.kt  — загрузка подписок
│   ├── ProfileRepository.kt    — серверы и подписки (JSON-файл)
│   └── SettingsRepository.kt   — настройки (DataStore)
├── service/
│   ├── BoxVpnService.kt        — VpnService + платформенный интерфейс libbox
│   ├── DefaultNetworkMonitor.kt
│   ├── TrafficMonitor.kt       — скорость/трафик из TrafficStats
│   ├── VpnState.kt             — состояние и управление туннелем
│   └── VpnTileService.kt       — плитка быстрых настроек
└── ui/                         — Jetpack Compose + Material 3 Expressive
    ├── home/                   — главная: сервер, кнопка, таймер, трафик, график
    ├── exclusions/             — исключения приложений
    └── settings/               — настройки и «О приложении»
```
